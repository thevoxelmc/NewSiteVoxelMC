About VoxelMC

VoxelMC is a community-focused SMP built for players who want a fun, balanced, and engaging Minecraft experience without unfair advantages.

Vanilla+ Gameplay

Enjoy Minecraft with quality-of-life improvements while keeping the core survival feeling intact.

Balanced Economy

Build wealth, trade with players, and grow your empire in a fair player-driven economy.

No Pay-To-Win

We believe skill, creativity, and community should matter more than spending money.

Growing Community

Join early and become part of the foundation of an exciting new SMP community.

How To Join

Getting started on VoxelMC only takes a few minutes.

1

Launch Minecraft Java Edition

Open Minecraft Java Edition and make sure you are using the supported version of the server.

2

Add The Server

Go to Multiplayer → Add Server and enter the server IP: MC.PlayVoxel.Net

3

Start Your Adventure

Join the server, meet the community, build your base, and enjoy the VoxelMC experience.
